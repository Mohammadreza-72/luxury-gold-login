# Luxury Gold Login

افزونهٔ وردپرس برای شخصی‌سازی صفحهٔ ورود با طراحی مشکی و طلایی، انتخاب لوگو از کتابخانهٔ رسانه و تنظیم عنوان و توضیحات.

**سازنده:** Mohammadreza Kazemi (محمدرضا کاظمی)

## نصب

1. پوشه‌ای با نام `luxury-gold-login` در مسیر `wp-content/plugins/` بسازید.
2. فایل `luxury-gold-login.php` را داخل آن قرار دهید.
3. افزونهٔ Luxury Gold Login را از بخش افزونه‌های پیشخوان وردپرس فعال کنید.
4. تنظیمات را از مسیر «تنظیمات» و سپس «طراحی صفحه ورود» تغییر دهید.
